# Timekeeper-for-soba-making
そば打ち段位認定会に向けた練習用
**そば打ち段位認定会のタイマーアプリ**です。
そば打ちの工程は「時間の管理」が非常に重要です。  
このアプリは、10分・20分・30分・残り時間など、  
そば打ちに必要なタイミングを自動で音声案内します。
---

## 📱 特徴

- **10分・20分・30分の経過時間を音声で案内**
- **35〜40分の残り時間を自動アナウンス**
- **そば打ち中でも見やすい大きな画面**
- **時間とメッセージを自由に設定可能**
- **Androidスマホ・タブレット対応**
## iOS
iOS版のXcodeプロジェクトを追加しました。
